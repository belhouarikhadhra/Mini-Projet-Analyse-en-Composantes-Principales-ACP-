# ACP — Body Measurements

This project applies Principal Component Analysis (PCA), or Analyse en Composantes Principales (ACP), to anthropometric data from 507 individuals (260 women and 247 men) with 25 variables, including 24 quantitative body measurements and one binary sex variable.

The objective is to explore correlations between body measurements, reduce data dimensionality, analyze explained variance, and visualize relationships between individuals and variables using Python.
